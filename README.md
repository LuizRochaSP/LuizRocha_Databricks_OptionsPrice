# LuizRocha_Databricks_OptionsPrice

Precificação e risco de opções exóticas sobre o Ibovespa e o S&P 500 (em US$ ou em R$), com pipeline diário no
Databricks e dashboard em Databricks Apps.

- Projeto principal: [`ibov-barrier-option-mvp/`](ibov-barrier-option-mvp/README.md)
- Dashboard de opções (Streamlit / Databricks Apps): [`ibov-barrier-option-mvp/dashboard/`](ibov-barrier-option-mvp/dashboard/README.md)
- Renda fixa pública brasileira: projeto separado, no branch `feature/renda-fixa-publica` (pasta
  `renda-fixa-publica/`, com app próprio)
